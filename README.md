Website Artikel Aqeela Calista
Fungsi Web

Website ini dibuat untuk memberikan informasi mengenai Aqeela Calista, mulai dari profil, perjalanan karier, hingga artikel tentang dirinya. Website dibuat dengan tampilan sederhana dan mudah digunakan.

Fitur Utama
Beranda yang berisi pengenalan Aqeela Calista.
Halaman Profil yang berisi biodata dan informasi tentang Aqeela Calista.
Halaman Karier yang berisi perjalanan karier Aqeela Calista.
Halaman Artikel yang berisi artikel dan informasi terkait.
Navigasi antar halaman.
Fitur mode gelap.
Form komentar pada halaman Artikel.
Tampilan website yang responsif untuk berbagai ukuran layar.

Teknologi yang Digunakan
HTML untuk membuat struktur halaman.
CSS untuk mengatur tampilan dan desain website.
JavaScript untuk fitur interaktif seperti mode gelap dan komentar.
GitHub untuk menyimpan dan mengelola proyek.

Cara Menjalankan Website
Download atau clone repository website.
Buka folder proyek menggunakan Visual Studio Code.
Pastikan file index.html, profil.html, karier.html, artikel.html, style.css, dan script.js berada dalam satu folder.
Pastikan file gambar seperti A1.jpg, A2.jpg, A3.jpg, dan A4.jpg berada di folder yang sesuai.
Buka file index.html menggunakan browser.
Website siap digunakan dan dapat berpindah halaman melalui menu navigasi.
